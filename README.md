## গেমটা কী

একটা ডেক-বিল্ডিং ডানজিয়ন ক্রলার। প্রতিটা তলায় একটা রাস্তা বেছে নেন —
লড়াই, বিশ্রাম, দোকান, রহস্য। লড়াইয়ে হাতে কার্ড আসে, শক্তি (⚡) খরচ করে
শত্রু মারেন বা বর্ম নেন। পালা শেষ হলে শত্রুরা আঘাত করে।

মরে গেলে শুরু থেকে। কিন্তু যতবার খেলবেন, ততবার নতুন কার্ড পাবেন —
আর ডেকটাই আপনার আসল অস্ত্র।

## চব্বিশ তলা

| তলা | কী আছে |
|---|---|
| ১–৭ | ইঁদুর, বাদুড়, স্লাইম, কঙ্কাল |
| **৮** | **প্রহরী** — প্রথম বস |
| ৯–১৫ | ভূত, পাথর দানব, সাপ |
| **১৬** | **ছায়া রাজা** — দ্বিতীয় বস |
| ১৭–২৩ | প্রেত, টাইটান, জাদুকর |
| **২৪** | **গভীরের হৃদয়** — শেষ প্রহরী |

## সংখ্যা

- **কার্ড:** ২৮টা, ১৪টা শান দেওয়া যায়
- **শত্রু:** ১৪ ধরনের সাধারণ + ৩ বস
- **রেলিক:** ৬টা, স্থায়ী ক্ষমতা
- **শক্তি:** ৩ → ৪ (৯ তলা) → ৫ (১৭ তলা)
- **গভীরতা:** ৫ স্তর, প্রতিটা কঠিনতর

## কঠিন, কিন্তু সম্ভব

শেষ পর্যন্ত পৌঁছানো কঠিন — প্রথম দশবারে হয়তো পারবেন না।
স্মার্ট খেলোয়াড় ৬ রানে ১ বার শেষ করে। কিন্তু প্রতিটা রান আগের চেয়ে
সহজ লাগে, কারণ আপনি শিখছেন কোন কার্ড কখন খেলতে হয়।
