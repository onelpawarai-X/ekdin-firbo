## গেমটা কী

ছয় বছর। ছয়টা ধাপ। প্রতিটা ধাপে দুই-তিনটা পথ — কোনটা বেছে নেবেন সেটা আপনার।

চারটা জিনিস গণনা হয়:

| | |
|---|---|
| **টাকা** | হাতে থাকা জমা লাভ |
| **টিম** | পাশে থাকা মানুষ — ১ থেকে ৫০০ |
| **মানুষ** | রোজ যারা ব্যবহার করে — ০ থেকে ৫ কোটি |
| **বিশ্বাস** | সবচেয়ে দুষ্প্রাপ্য জিনিস — ০ থেকে ১০০% |

টাকা দিয়ে অনেক কিছু কেনা যায়। কিন্তু **বিশ্বাস একবার ভাঙলে আর ফেরে না** — আর শেষ গ্রেড সেটাই ঠিক করে।

## খেলার নিয়ম

- **কীবোর্ড:** `১` `২` `৩` দিয়ে সিদ্ধান্ত, `Enter` দিয়ে এগিয়ে যাওয়া
- **মোবাইল:** ট্যাপ করলেই হবে — ৩২০px পর্যন্ত কাজ করে
- সেরা ফলাফল ব্রাউজারে সেভ থাকে
- শেষে আপনার সব সিদ্ধান্তের তালিকা দেখা যায়
